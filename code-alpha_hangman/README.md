# Hangman Game 🎮

## Project Overview
Hangman is a simple text-based word guessing game developed using Python. The player has to guess a hidden word one letter at a time. The game ends when the player guesses the complete word or uses all six incorrect guesses.

## Features
- Randomly selects a word from a list of five predefined words.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters and hides unguessed letters.
- Limits incorrect guesses to six.
- Displays a winning or losing message.
- Runs in the console without graphics or audio.

## Technologies Used
- Python 3
- Random module

## Key Concepts
- Random word selection
- While loops
- If-else statements
- Strings and lists
- User input and output

## How to Run
1. Install Python 3 on your computer.
2. Save the code in a file named `hangman.py`.
3. Open a terminal or command prompt in the project folder.
4. Run the following command:

```bash
python hangman.py
```

If required, use `python3 hangman.py` instead.

## How to Play
1. Run the program.
2. Read the hidden word displayed as underscores.
3. Enter one letter as your guess.
4. Continue guessing until you reveal the word or use all six incorrect guesses.
